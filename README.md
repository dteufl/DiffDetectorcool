# DiffDetector

Eine ASP.NET Core MVC Webanwendung zur Analyse von League of Legends Matches.

## Beschreibung
Dieses Projekt wurde im Rahmen meiner Ausbildung entwickelt.
Die Anwendung ermöglicht es, Matches zu speichern und Statistiken wie Winrate
für Champions und Rollen zu berechnen.

## Funktionen
- Matches hinzufügen
- Winrate berechnen
- Champion Statistiken anzeigen

## Technologien
- ASP.NET Core MVC
- Entity Framework
- SQLite
- Bootstrap
- Docker
